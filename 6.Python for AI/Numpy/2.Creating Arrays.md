The most important way to create a NumPy array is `np.array()`.

## 1. `np.array()`

### 1D Array

```python
import numpy as np

arr = np.array([1, 2, 3, 4])
```

### 2D Array

```python
arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

---

## 2. Common Array-Creation Functions

You only need to know these basics:

### `np.zeros()`

Creates an array filled with `0`.

```python
np.zeros(5)
```

Output:

```python
[0. 0. 0. 0. 0.]
```

2D:

```python
np.zeros((2, 3))
```

---

### `np.ones()`

Creates an array filled with `1`.

```python
np.ones(4)
```

Output:

```python
[1. 1. 1. 1.]
```

---

### `np.arange()`

Creates numbers within a given range.

```python
np.arange(1, 6)
```

Output:

```python
[1 2 3 4 5]
```

Syntax:

```python
np.arange(start, stop, step)
```

Example:

```python
np.arange(0, 10, 2)
```

Output:

```python
[0 2 4 6 8]
```

**Remember:** `stop` is not included.

---

### `np.linspace()`

Creates a specified number of **evenly spaced values**.

```python
np.linspace(0, 10, 5)
```

Output:

```python
[ 0.   2.5  5.   7.5 10. ]
```

Here, `5` means **generate 5 values**.

---

## 3. Specifying Data Type

You can specify the data type using `dtype`.

```python
arr = np.array([1, 2, 3], dtype=float)
```

Output:

```python
[1. 2. 3.]
```

---

## ⭐ What You Actually Need to Remember

| Function | Purpose |
| --- | --- |
| `np.array()` | Create an array from values |
| `np.zeros()` | Create array of zeros |
| `np.ones()` | Create array of ones |
| `np.arange()` | Create values in a range |
| `np.linspace()` | Create evenly spaced values |

### Interview Question

**Q: What is the difference between `arange()` and `linspace()`?**

> `arange()` generates values based on a **step size**, while `linspace()` generates a specified **number of evenly spaced values**.
